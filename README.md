# 台股排行榜

每個交易日自動抓取臺灣證券交易所與證券櫃檯買賣中心的公開資料，
計算五張排行榜，並標記每檔股票連續在榜幾天、是不是今天才進榜。

網站：https://jhunterxsaxon.github.io/（repo 建好後會有正確網址）

## 五張榜單

| 榜單 | 算法 |
|---|---|
| 成交量榜 | 當日成交股數 |
| 成交金額榜 | 當日成交金額 |
| 振幅榜 | （最高價 − 最低價）÷ **前一交易日收盤價**，有流動性門檻 |
| 三大法人買超榜 | 買賣超金額（官方只提供上櫃） |
| 三大法人賣超榜 | 同上 |

每檔都會標記：🆕 新進榜／連續 N 天／↩ 回榜／✖ 掉榜／排名變化。
名次可以自己調（10～300），**連續天數會跟著重算** ——
「連續在前 50 名 5 天」和「連續在前 100 名 5 天」是兩件不同的事。

## 為什麼排名是自己算的

官方確實有排行端點，但：

- 證交所 `MI_INDEX20` **只有前 20 名**，而且只有上市
- 櫃買的排行是「歷史區間統計」或「盤中」，不是當日收盤排名
- **沒有任何端點提供「上市＋上櫃合併」的當日排名**

最關鍵的是：**官方前 20 名裡有 13 檔是 ETF**（2026-11-09 實測，
前三名全是正 2／反 1 槓桿型）。直接用的話，「前 100 檔股票」
會有三分之二不是股票。

本站用官方的**上市／上櫃公司基本資料**當白名單過濾
（ETF 不是公司，根本不在那張表裡），再加一層「代號恰好四位純數字」，
自動排除 ETF、權證、特別股、TDR 與興櫃。

排除 ETF 後，本站算出的相對順序與官方完全一致（友達官方第 9 → 本站第 1，
聯電官方第 10 → 本站第 2），等於互相驗證。

## 歷史是從上線那天開始累積的

官方 API **不支援查詢過去的日期**（實測確認：傳 `date` 參數會被忽略，
一律回傳最新交易日）。所以本站補不回上線前的資料，
「連續在榜天數」要累積一段時間才有參考價值。

## 更新時間

- 每個交易日台灣時間 **18:30** 自動抓取
- 若當時官方尚未更新，**22:30** 再試一次
  （第二次會先確認有沒有新資料，沒有就立刻結束，不會產生多餘的 commit）

★ GitHub 的排程會延遲，實測平均 3 小時、最糟 7 小時，所以實際執行時間會晚一些。
網站上會同時顯示「資料日期」與「更新時間」—— 這是兩件不同的事。

## 分析與選股

回測、選股清單、分群結果需要五年歷史與財報資料。那些資料的來源
**不允許再散布**，所以是在本機電腦上計算，只把**結論**推送上來。

因此分析頁**不會每天自動更新**，頁面上會標示它的產生時間。

## 技術

- 抓取只用 Python 標準函式庫（`urllib`、`json`、`sqlite3`），**零第三方套件**
- 網頁零依賴、零 CDN，純 HTML/CSS/JS
- 存檔用 JSON（git 友善、瀏覽器可直接讀），運算時才臨時灌進 SQLite
- 榜單邏輯與本機版**共用同一份 `ranking.py`**，不會算出不同結果

```
core/          只放官方來源相關的模組（★ 刻意沒有 finmind.py）
fetch.py       GitHub Actions 每天跑這支
data/          輸出的 JSON
index.html     網頁
```

## 資料來源與授權

本站的行情、融資融券、三大法人、本益比等資料來自
**臺灣證券交易所**與**證券櫃檯買賣中心**，
依「**政府資料開放授權條款第 1 版**」使用。

★ 該條款規定未依格式標示來源者，授權視為自始未取得，
因此網站頁尾與本檔案都載明出處。

**資料僅供參考，不構成投資建議。回測結果不代表未來績效。**
